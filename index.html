Cara kerjanya

  • Mode kualitas tinggi memakai API key Gemini milikmu sendiri, disimpan hanya di browser ini dan bisa diganti kapan saja.
  • Naskah panjang dipecah per bagian, dibuat satu per satu, lalu digabung jadi satu file MP3. Kalau limit per menit tercapai, halaman menunggu otomatis lalu melanjutkan.

  • Mode Standar (Kokoro, sekitar 90 MB) hanya cocok untuk teks bahasa Inggris.
